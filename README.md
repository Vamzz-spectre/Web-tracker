# 💰 Money Tracker Pro

Money Tracker Pro adalah aplikasi web **pencatat keuangan pribadi** berbasis **HTML, CSS, dan JavaScript** (tanpa backend) yang modern, responsif, dan mudah digunakan.  
Data disimpan secara **localStorage**, jadi aman dan langsung jalan tanpa database.

---

## ✨ Fitur Utama

- 📊 **Dashboard interaktif**
  - Saldo total
  - Total pemasukan & pengeluaran
  - Statistik transaksi
- ➕ **Tambah transaksi cepat**
  - Pemasukan & pengeluaran
  - Kategori fleksibel
- 🗂 **Manajemen transaksi**
  - Edit & hapus transaksi
  - Filter (semua / pemasukan / pengeluaran)
  - Pencarian transaksi
- 📈 **Grafik visual**
  - Pengeluaran per kategori
  - Tren keuangan bulanan
- ⚙ **Pengaturan**
  - Mata uang (IDR, USD, dll)
  - Tema gelap / terang / otomatis
  - Auto backup
- 📤 **Export data**
- 📱 **Responsive**
  - Optimal di HP & laptop
- 🔔 **Notifikasi (Toast)**
- 📴 **Offline ready** (tanpa internet)

---

## 🛠 Teknologi yang Digunakan

- **HTML5**
- **CSS3** (Modern UI, Responsive, Dark Mode)
- **JavaScript (Vanilla JS)**
- **Chart.js** (Grafik)
- **Font Awesome** (Icon)
